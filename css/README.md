# Struktur CSS

- `base.css`: stylesheet utama yang dipindahkan dari `style.css`.
- `components.css`: tempat aturan komponen baru seperti tombol, modal,
  absensi, notifikasi, dan formulir.

`style.css` tetap dipertahankan sebagai entry point agar referensi lama di
`index.html` tetap bekerja.
